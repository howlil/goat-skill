# Dependency-aware interview

Use this technique in the current mode for an explicit interview or dependent decisions across rounds. Apply the question and authorization rules in SKILL.md section 4. For a settled request, focus on the interview purpose and confirm settled facts without inventing blockers.

## Run the interview

1. Ground available facts. Identify the choice that changes the remaining questions, often the consumer, outcome, or scope.
2. Number questions if that helps the requester answer. Make each answerable briefly, with a safe recommendation and its effect. A reply accepting defaults can settle delegated reversible choices. Apply the explicit authorization rule before high-impact effects.
3. Use each answer to update only the affected decisions. A brief recap is useful if earlier answers were revised or the requester would otherwise lose track. For a contradiction, overloaded term, or vague outcome that affects the build, give one scenario or observation that distinguishes the choices. Stop when the remaining questions would no longer change the build.

Return the proportionate contract or blocked decision using SKILL.md. An ordinary ready handoff can follow once the requester has settled the material choices and authorized the work.
