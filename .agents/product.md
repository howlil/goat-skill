# Product

## Problem
Developers need reusable SWE agent skills installable across Codex, Claude Code, Agy, and skills.sh without maintaining platform-specific skill copies.

## Current scope
Bootstrap the repository, establish distribution manifests, and provide a minimal structural validator. **No skills have been requested for implementation.**

## Constraints
Canonical `skills/` content only. No runtime, MCP, hooks, or agents by default. No publication or release yet.

## Proof
Plugin identity/version metadata is consistent; repository validation passes; `skills/` contains no `SKILL.md`.

## Open decisions
First skill definition, exact behavior evaluation, and license for public redistribution.
